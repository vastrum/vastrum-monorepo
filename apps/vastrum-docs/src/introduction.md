# Introduction

Vastrum is a protocol for hosting decentralized user owned websites and services.

While great progress has been done in decentralizing websites, there are still many problems.

- Making interactive websites such as forums is very difficult using existing solutions

- While torrents have proven very resilent, they frequently die with no seeders. Making the data lost forever

- Most decentralized websites rely on trusted centralized HTTP gateways 

Vastrum intends to solve these problems by

- Creating a decentralized backend "contract" runtime that allows you to create dynamic websites with state such as forums

- Giving hard guarantees of state persistence by using blockchain consensus, any data hosted on Vastrum will be there forever

- Connect directly the Vastrum P2P network using WebRTC

If you are interested in the technical details there is more information in this docs page, otherwise you can check out the prototype apps hosted on Vastrum.
